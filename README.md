# ゴルフナビ（スマホ用）

Android の Chrome で使うゴルフナビです。GPS の現在地から次を表示します。

- グリーンの **前・中央・奥** までの残り距離（ヤード）
- **ハザード**（バンカー・池・OB）の手前／越えるまでの距離（現在地より前にあるものだけ、近い順）
- グリーンとの **高低差**（↑打ち上げ／↓打ち下ろし。国土地理院の5mレーザー標高データ）と、高低差を入れた **実質の距離**（例: 「↓ 26m 打ち下ろし　実質 150y」。高さ1mにつき1mを足し引きした目安。風・気温は入れていません。差が2m未満なら出しません）
  - 実質の距離は、グリーンの前・奥（数字の下に小さく）、ハザード（「↓29m 実質 181 / 205」）、地図でタップした地点（「ティーから 99y（↓19m・実質 79y）・グリーンまで 278y（↓7m・実質 271y）」）にも出ます。ハザードはその中心の標高で計算します（OB などの線は出しません）
- **コースレイアウト**（航空写真の上にティー・グリーン・ハザードを表示）
- 地図をタップした地点までの距離と、そこからグリーンまでの距離（刻みどころの確認）
- **2グリーン**（ベント／高麗）の切り替え

対象コース: 太田双葉カントリークラブ（愛宕・天王・御所ノ入の27ホール）。
OpenStreetMap にはこのコースのホール情報がないため、**ホールは自分で登録して使います**（1ホール数分）。

---

## 1. コースを登録する（最初に1回）

1. `editor.html`（コース登録画面）を開きます。PC の大きな画面のほうが楽です。
2. 上の欄で「愛宕」「1番」を選び、Par を選びます。ホール番号の左右の「◀」「次 ▶」で前後のホールへ移れます（9番の次は次のハーフの1番）。最後に開いていたコース・ホールは覚えていて、閉じて開き直してもそこから続けられます。
3. 下のボタンを押してから、航空写真をタップします。

| ボタン | タップする場所 |
|---|---|
| ティー | ティーグラウンド（種類を選べます） |
| グリーン中央 | グリーンの真ん中（**必須**。これが無いと距離が出ません） |
| グリーン前／奥 | グリーンの手前の端／奥の端 |
| グリーンの形 | グリーンの縁を順にタップ →「形を確定」。打つ方向に合わせて前・奥が自動で決まります |
| ハザード（点） | 1回目＝手前、続けて2回目＝奥。種類（バンカー・池・OB）と名前を先に選びます |
| ハザード（形） | ハザードの縁を順にタップ →「形を確定」 |
| OSMの池を選ぶ | 青い点線で描かれた池をタップすると、そのまま池ハザードになります |

- 標高は登録したときに自動で取得されます（一覧に「標高 157.1m」などと出ます）。

### 登録した内容の修正
一覧の行、または地図の図形（ティー・グリーン・ハザード）を **タップ** すると修正画面が開きます（地図のタップは、上の登録ボタンを選んでいないとき）。
- ハザードの種類・名前・どのグリーン用か、ティーの種類を変えられます（変えるとすぐ保存）
- 「位置を調整（移動・回転）」で全体を動かす、「点を1つずつ動かす」で形・線の点をドラッグして直す（地図が大きく寄ります）、「削除」で消す（確認あり）
- 描きかけの形や、動かしかけの位置があるときに行を押すと、捨ててよいか確認が出ます

### 位置の調整（移動・回転）
登録した内容が写真とずれているときは、修正画面の **「位置を調整」** で位置を合わせます。一覧の上の「ホール全体を移動・回転」で、そのホールのものをまとめて動かすこともできます（OB の線がまとめてずれているときなど）。
- 矢印で東西南北へ動かします（1回の幅は 0.5m〜10m）。⟲ ⟳ で中心のまわりに回します（1〜90°。1点だけのものは回せません）
- 地図の黄色い印をドラッグする、または地図をタップした場所へ動かすこともできます。パソコンでは矢印キー（Shift で5倍）と [ ] キーでも操作できます
- グリーンの形を動かすと、中央・前・奥も一緒に動きます
- 「確定」で保存します。「やめる」・別のホールや道具に切り替えると元の位置に戻ります（確定するまでは保存されません）。「点を1つずつ動かす」も同じです
- ティーやグリーン中央などは、確定した後に新しい場所の標高を取り直します

### 現地で GPS を使って記録する
登録画面の「GPSで記録」を押すと、スマホの GPS で形や線を記録できます（記録中は画面が消えません）。
- **グリーンの形**: 「登録するグリーン」を選び、グリーンの縁に沿って一周 →「完了して登録」
- **バンカー・池の形**: 下の欄で種類（バンカー・池）と名前を選び、縁に沿って一周
- **OB・赤杭の線**: 種類で「OB」か「赤杭（ペナルティー）」を選び、杭に沿って歩く。杭の前で「この地点を追加」を押してもよい
- 歩くと 2.5m ごとに自動で点が入ります（GPS の誤差が 12m を超えるときは入りません）。「1点戻す」で直せます
- GPS の誤差は ±3〜5m 程度なので、形はやや粗くなります

### 2グリーンのホール

1. 上の「登録するグリーン」で **ベントグリーン** を選び、グリーン中央・前・奥などを登録します。
2. 「登録するグリーン」を **高麗グリーン** に切り替えて、同じように登録します。ホール番号の横に「（2G）」と出れば完了です。
3. ハザードを置くとき、右側の欄で対象を選べます。
   - **どのグリーンでも**: フェアウェイのバンカーや池など、両方のグリーンで関係するもの
   - **ベントグリーン用／高麗グリーン用**: そのグリーンを囲むガードバンカーなど。使っていないグリーンのものはプレー画面に出ません
4. 呼び名は「呼び名を変更」で変えられます（例: A、B / 左、右）。太田双葉は「ベント、高麗」にしてあります。
   - 呼び名を減らすことはできません（登録済みのグリーンが選べなくなるため）。
- 登録内容は **その端末に自動保存** されます。
- 間違えたら一覧の「削除」を押します。

## 2. スマホで使う

1. Chrome で公開先の URL を開き、メニューの「ホーム画面に追加」でアプリとして入れます。
2. ☰ →「このコースの地図を端末に保存」を **Wi-Fi のある所で** 押します（約330枚。圏外でも地図と高低差が出ます）。
3. 前半・後半のコースと **使うグリーン**（その日のグリーン）を選んで「このコースで始める」。
   - 「使うグリーン」は、2グリーンのホールを1つ以上登録すると表示されます。
4. ◀ ▶ でホールを切り替えます。
   - 2グリーンのホールでは、数字の上に「ベントグリーン 使用中 ⇄ 高麗に切替」ボタンが出ます。押すと **以降の全ホール** がそのグリーンになります（1グリーンのホールはそのまま）。
   - 使ったグリーンはコースごとに端末に覚え、次のラウンドの初期値になります。
5. 初回は位置情報の許可を求められるので「許可」を選びます。

### コースの外での下見
自宅などコースから500m以上離れているとき（または GPS が使えないとき）は、自動で **下見モード** になります。
- 距離・高低差・ハザードは **ティー（レギュラー）から** の値になり、数字が青色で表示されます
- 地図をタップすると、ティーからその地点まで／そこからグリーンまでの距離を測れます
- 上のホール名を押すと **ホール一覧**（Par・ヤード付き）が開き、好きなホールに移れます
- コースに着いて GPS が届くと、自動で現在地からの距離に戻ります
- 圏外で下見するなら、先に「このコースの地図を端末に保存」をしておきます

### 屋外表示（日差しの下で見やすく）
地図の右上の **「☀ 屋外」** を押すと、白地に黒の太く大きな文字の表示に切り替わります（グリーンまでの数字は約1.4倍）。もう一度押すと元の表示に戻ります。選んだ表示は端末が覚えています。
- 地図の上のボタンや GPS の誤差の表示も白地に黒になり、スマホの上端の帯も白になります
- 下の欄が画面に収まらないときは、欄の中を上下にスクロールできます（地図は画面の3割を必ず残します）

### GPS の誤差の目安
地図の左上に、今の GPS の誤差の目安が出ます（1秒ごとに更新。「地図を大きく」でも出ます）。
- 例: 「● GPS ±4y 良好」。色の段階は 緑＝良好（±5m 以内）・黄緑＝まずまず（±10m）・黄＝やや悪い（±20m）・赤＝悪い（それ以上）
- 最後の位置から3秒以上たつと「○秒前」、15秒以上届かないと灰色で「止まっています」と出ます（このとき距離の数字も灰色）
- 誤差が約22y（20m）を超えるときも距離の数字が灰色になります。空の開けた所で少し待つと良くなります
- 押すと説明が出ます。位置情報が許可されていないとき・下見中・手で指定中・コースの外にいるときは、そのことを表示します

### ピン位置
高低差の下の「ピン 手前 ／ 中 ／ 奥」で、その日のピン位置を選ぶと、大きい数字が **ピンまでの距離** になります（「実質」もピンまでで計算）。地図にはピンの位置が黄色い点で出ます。
- ピンは、ティーからグリーン中央の向きで見たグリーンの前端〜奥端の 1/4（手前）・1/2（中）・3/4（奥）の所とみなします（目安）
- ホールごと・グリーンごとに選び、その日のあいだ覚えています（翌日は未選択に戻ります）。同じボタンをもう一度押すと、グリーン中央に戻ります
- グリーンの形も前・奥の点も無いホールでは使えません。「地図を大きく」のときはボタンを隠します（選んだピンの距離はそのまま出ます）

### ショット地点の記録と飛距離（自分だけ）
ピンの下の行で、番手を選び、**打つ場所で「ここから打つ」** を押します。次に打つ場所でまた押すと、その間の距離が前のショットの飛距離になります。
- 例: ティーで「1W」を選んで押す → ボールの所で「7I」を選んで押す → 1W の飛距離が出る（右の欄に「1W 235y」）。グリーンに乗ったら、もう一度押して終わり
- 右の欄に、前のショットの飛距離と、最後に押した地点から今の場所までの距離が出ます。地図には記録した地点と番手が出ます
- 間違えて押したら「取消」（このホールの最後の記録を消します）。自動でホールが切り替わる前に次のティーで押すと、前のホールに入るので気をつけてください
- 右の欄（または ☰ →「クラブ別の飛距離」）を押すと、**番手ごとの回数・平均・最大** が出ます。地点の間の直線距離（ランを含む）で、GPS の誤差（±5m ほど）を含みます。番手なしと、5y 未満・437y を超えるもの（押し忘れなど）は入れません
- GPS が止まっているとき・下見中は記録しません。「位置指定」で地図に置いた位置で記録するときは確認が出ます
- 記録はラウンド（スコアカード）ごとに分けるので、同じ日に同じコースを2回回っても混ざりません。バックアップのファイルにも一緒に入ります
- **番手の設定**: 番手の選択欄のいちばん下「⚙ 番手を設定…」（またはクラブ別の飛距離の画面の「番手を設定」）で、選べる番手を自分のクラブに合わせられます
  - ↑↓で並べ替え、「削除」で外す。候補（2U・3I・GW・52° など）から追加するほか、名前を入れて追加もできます（8文字まで。例: チッパー）
  - 候補から足すと、長い番手から短い番手の順で近い位置に入ります。「初めの並びに戻す」で元に戻せます
  - 外した番手のこれまでの飛距離は消えず、クラブ別の表の後ろに出ます。番手の設定はバックアップのファイルにも入り、まだ設定していない端末で読み込むと取り込まれます

### スコア入力
数字欄の下の行で、今のホールの打数とパット数を − ／ ＋ で入れます。左端のボタンに「ホール番号」と「入力する人の名前」が出ます。

**複数人**: ラウンド設定の「スコアを入力する人数」（1〜4人）と名前を入れて「このコースで始める」を押します。
- 入力行の名前ボタンを押すと、次の人に切り替わります（その人の打数・パットを入れる）
- スコアカードは人ごとの列で、OUT・IN・合計と Par との差が出ます
- 途中で人数・名前を変えるときは、スコアカードの「人数・名前を変える」から。入力済みの人を外すときは確認が出ます
- 名前を書き換えると、その欄のスコアは新しい名前に付きます（人を入れ替えるときは「新しいカードにする」）
- **メンバー一覧**: 2人以上のときは入力行の下に、全員の「このホールの打数（パット）」と「合計・Par との差」が並びます。行を押すとその人の入力に切り替わります（「地図を大きく」のときは隠れます）
  - 「▼ メンバー一覧」を押すと畳めます。畳むと地図が広がり、見出しに全員の合計だけ1行で出ます（例: ▶ メンバー 自分 5 +1 ・ 太郎 4 E）。もう一度押すと開きます。畳んだかどうかは端末が覚えています

**OB の数（自分だけ）**: 入力行の下の「OB（自分）」で、自分（ラウンド設定の1人目）のそのホールの OB の数を − ／ ＋ で入れます。
- ほかの人を入力しているときは押せません（薄く表示）
- 「このラウンド パット n ・ OB n」に合計が出ます。スコアカードでは自分の列の右に OB の列があり、過去の記録の一覧にも OB の合計が出ます

**自分のパット数の合計**: 自分（1人目）だけ、パット数の合計も出ます。
- プレー画面の「このラウンド パット 32 ・ OB 2」、メンバー一覧（畳んだ見出しも）の「P32 OB2」
- スコアカードでは自分の列の右に「パット」「OB」の列があり、ホールごとの数と OUT・IN・合計が出ます。ほかの人のパット数は、これまでどおり打数の右の小さい数字です
- 過去の記録の一覧

- 最初に打数の ＋ を押すと Par の数から、− を押すと Par−1 から始まります。パットは 1 から
- 右端の「計」は合計打数と Par との差です。押すと **スコアカード**（OUT・IN・合計）が開き、行を押すとそのホールに移れます
- スコアは端末に自動保存されます。最後の入力から12時間以内なら、アプリを閉じても続きから入力できます
- 別のコース・前後半でラウンドを始めるときは確認が出ます。前のスコアは端末に残り、元のコース・前後半を選び直すと戻ります
- 全ホール入力済みのカードで同じコースを始め直すと、新しいカードにするか確認が出ます（スコアカードの「新しいカードにする」でも可）

**過去の記録**: スコアカードまたはラウンド設定の「過去の記録」を押すと、これまでのラウンドが新しい順に並びます（日付・コース・前後半・人ごとの合計と Par との差）。押すとそのときのスコアカードを表示します（見るだけで、書き換えはできません）。
- 今入力中のカードも「今のカード」として一覧に出ます
- 記録を開いて「この記録を削除」を押すと、確認のあとその記録を消せます（元に戻せません）。入力中のカードは消せません
- 記録はこの端末の中だけに、最大200件まで残ります（古いものから消えます）。ブラウザのサイトデータを消すと記録も消えます

**バックアップ**: 過去の記録の画面の「ファイルに書き出す」で、今のカードと過去の記録を1つのファイル（golfnavi-scores-日付.json、ダウンロード フォルダ）に保存できます。機種変更やデータ消去に備えて、ときどき書き出しておくと安心です。
- 「ファイルから読み込む」でそのファイルを選ぶと、記録が戻ります。今の記録は消えず、無い記録だけが足されます（同じラウンドは新しい内容の方を残します。入力中のカードはそのまま）
- 記録が最大件数に達しているときは、それ以上は読み込みません（今の記録を押し出さないため）

### ホールの自動切り替え
次のホールのティー（30m以内）に約8秒とどまると、そのホールの表示に自動で切り替わります（前半9番→後半10Hも同様）。
- 切り替わるのは「次のホール」だけです。済んだホールや別のコースのティーの近くを通っても切り替わりません
- 今のグリーンのほうが近い間（パット中）は切り替わりません
- ◀ ▶ やホール一覧で手で選んだ後は、その場所から60m以上動くまで自動で切り替わりません
- GPS の誤差が大きいとき（±30m超）、「位置指定」中、下見中は切り替わりません
- ラウンド設定の「GPS でホールを自動で切り替える」で止められます

### 地図の見方
- 地図は **グリーンが上** になるよう、ホールごとに自動で回ります（ティーが下）。「ホール全体」を押すと元の向き・大きさに戻ります
- パネル上端の **「▼ 地図を大きく」** を押すと、下の数字欄が1行（前・中・奥と高低差）に畳まれ、地図が約2倍の高さになります。「▲ 詳細を表示」で元に戻ります（選んだ状態は端末に記憶）

画面の見方:
- 大きな緑の数字＝グリーン中央までのヤード。左右が前・奥です。
- 数字が灰色のときは GPS の誤差が大きい（±20m 超）状態です。
- 「位置を手で指定」を押すと、地図をタップした場所を現在地として計算します（自宅での確認用）。

## 3. PC で登録したデータをスマホへ移す

登録データは端末ごとに保存されるため、PC で登録したものはスマホに自動では届きません。

1. 登録画面で「ファイルに書き出す」→ `ota-futaba.json` が保存されます。
2. そのファイルを、このフォルダの `courses/ota-futaba.json` に上書きします。
3. ファイル先頭近くの `"revision"` を1つ上げます（例: 2 → 3）。上げると、古いデータが残っている端末に「新しいデータを使いますか？」と確認が出ます。
4. 公開先へ反映します（4章）。スマホでアプリを開き直すと新しいデータになります。

スマホで直接登録した場合は、この作業は要りません。ただし機種変更に備えて、ときどき「ファイルに書き出す」で控えを取ってください。

## 4. 公開（GitHub Pages）

スマホの GPS は **https** でないと動きません。PC から LAN 内に配信する方法（`http://192.168...`）では現在地が取れないので、GitHub Pages で公開します。

画面のファイル（html・js・css）を直したときは、公開前に次の2つを実行します。

```
npm run bump
npm test
```

`npm run bump` が版番号（`js/version.js`・`sw.js`・`version-lock.json`）をまとめて上げます。上げ忘れるとスマホに古い画面が残るため、上げ忘れたまま `npm test` を実行すると失敗するようにしてあります。
コースデータ（`courses/*.json`）だけを差し替えたときは、版上げは不要です（アプリは毎回最新のコースデータを取りに行きます）。

注意: GitHub Pages では、同じアカウントのほかのアプリ（筋トレアプリなど）と保存場所の区画が共通になります。このアプリの保存データは `golfnavi.` で始まる名前にして、混ざらないようにしています。

## 5. 開発者向け

```
index.html / js/play.js     プレー画面
editor.html / js/editor.js  コース登録画面
js/geo.js                   距離・方位・図形計算
js/elev.js                  標高（地理院の標高タイル → だめなら標高API）
js/store.js                 コースの読み書き
js/mapbase.js               地図・ホール描画・地図の事前保存
js/pwa.js, sw.js            オフライン対応・版ズレ検知
courses/                    コースデータ（index.json が一覧）
tests/                      npm test で実行
tools/make-icons.mjs        アイコン生成
```

- テスト: `npm test`
- PC での確認: `python tools/devserver.py` → `http://localhost:8766/`（ブラウザにファイルを保存させない設定。localhost なら PC の Chrome でも位置情報 API が動きます）
- 開発中は Service Worker が古いファイルを返すことがあります。Chrome の開発者ツール → Application → Service Workers →「Unregister」してから再読み込みしてください。
