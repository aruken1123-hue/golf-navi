# 太田双葉カントリークラブ コースデータの作り方と確からしさ

作成日: 2026-10-13（`courses/ota-futaba.json`）

## 使った資料
| 用途 | 資料 |
|---|---|
| ホール番号と並び | 公式サイトのコース図（愛宕・天王・御所ノ入）。図は実際の向きから約90度回転して描かれている |
| Par・ヤード（ベント／高麗別） | 楽天GORA コース情報のヤーデージ表（フロントティー＝レギュラー） |
| グリーンの位置と形 | 国土地理院「全国最新写真（シームレス）」。冬の写真で、グリーンだけが緑に写る |
| バンカー・池 | 国土地理院「簡易空中写真」（夏の写真）＋ OpenStreetMap の池 |
| 標高 | 国土地理院 標高タイル（5mメッシュ・レーザ測量） |
| OB等のライン | じゃらんゴルフのホール別レイアウト図のオレンジ線（v0.3.0 で追加） |

## 作り方
1. コース図を回転させて航空写真と照合し、どのフェアウェイが何番ホールかを決めた
2. グリーンは写真上の位置を起点に、同じ色の範囲を広げて輪郭を取った
3. ティーはフェアウェイの端に置き、ティー→グリーンの直線距離を表のヤードと比べて確かめた
4. 2つのグリーンのどちらがベントか高麗かは、表のヤード差（どちらが遠いか）で決めた
5. バンカー・池は夏の写真で位置を指定した（円で近似）

## 確からしさ
- **ティー→グリーンの距離が表と40ヤード以内**: 27ホール中 24ホール
- 表より40〜48ヤード短い: 愛宕4番・愛宕6番・御所ノ入1番（ドッグレッグ、またはティー位置の推定誤差）

### 気をつけてほしいホール
| ホール | 内容 |
|---|---|
| 愛宕4番 | 2つ目のグリーンが写真で確認できず、1グリーンのみ登録（高麗を選んでも同じグリーンを表示） |
| 天王1番 | 写真で見えたグリーンが1つだけ。1グリーンのみ登録 |
| 御所ノ入6番 | グリーン候補が2か所あり、距離が表に合うほう（東端）を採用。1グリーンのみ登録。現地で違えば登録画面で直してください |
| 天王6番 | 夏の写真の範囲のためグリーンの輪郭なし（中心と前後±12mのみ） |
| 2グリーンのベント／高麗 | ヤード差が小さいホール（6ヤード未満）は、どちらがベントか写真と表では決めきれていない |

### OB等のライン（v0.3.0）
- じゃらんゴルフのホール別図のオレンジ線を抜き出し、図のティー・グリーンを登録済みの位置に合わせて地図に載せた（80本）
- 図に凡例がなく、杭の色（白＝OB／赤＝ペナルティーエリア）は未確認。そのため次の2種類の名前で登録している
  - **OB（コース外周側）**: コースの外枠から40m以内にある線（34本）。敷地の外側なので OB の可能性が高い
  - **OB/赤杭（要確認）**: ホールとホールの間の線（46本）
- 図の縮尺・向きを2点で合わせているため、位置は±10〜20m程度ずれることがある
- 御所ノ入6番は図の形とこちらのティー・グリーンの推定が合わず、線を登録していない
- 愛宕1・2番、御所ノ入5番は図にオレンジ線がない
- プレー画面では線までの最短距離だけを表示する（「越え」は出さない）。地図では白の破線

### 登録していないもの
- ティーはレギュラー（フロント）のみ。位置は推定（±20m程度）

## 現地で直すには
登録画面（`editor.html`）でホールを選び、グリーン・ハザードを置き直してください。
端末内に保存され、そちらが優先されます。正しいデータを皆で使うには「ファイルに書き出す」→ `courses/ota-futaba.json` に置いて公開します。
