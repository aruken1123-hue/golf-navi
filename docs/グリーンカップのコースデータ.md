# グリーンカップゴルフクラブ（ショートコース）のコースデータ

作成日: 2026-10-22（`courses/greencup.json`、revision 1）

群馬県桐生市境野町7-1858。9ホール・Par 30・1553ヤード。航空写真とホール別のレイアウト図から**自動で作成**しました。現地で違っていたら、登録画面（パソコンなら `pc-edit.bat`）で直してください。

## 使った資料
| 用途 | 資料 |
|---|---|
| Par・ヤード・ハンディキャップ・ホール別レイアウト図・ひとこと | GreenOn のコース情報（利用者から教えてもらったページ） |
| グリーン・ティー・バンカーの位置 | 国土地理院の航空写真（簡易空中写真、0.5m/画素） |
| コースの外枠・池の形 | OpenStreetMap |
| 標高 | 国土地理院 標高タイル（5m） |

ショットナビ・楽天GORA は、作成時に一時停止・メンテナンス中で使えませんでした。

## 作り方
1. 写真で、円形のグリーン・ティーの位置と、2つの池（北の池・小島のある南の池）を拾う
2. ホール別の図のグリーン・池・まわりの円を写真に重ねる置き方を総当たりで探し、点数の高いものを選ぶ（4番は池と小島がぴったり重なることを目で確かめた）
3. 「前のホールのグリーンの近くに次のティー」で9ホールが一周につながることを確かめた（1番のティーは西側の建物の近く）
4. 7番は東側の通路の先にある2つの円を、写真を拡大して目で決めた
5. グリーンの形は画像AIで写真から取った（15か所すべて。ショートコースはグリーンが小さいので、90㎡以上を採用）

## グリーンの呼び名
2グリーンのホール（1・4・5・6・7・9番）は、**打つ方向から見て「左」「右」**と呼んでいます。2・3・8番は1グリーンです。コース側の呼び名（A/B など）と違えば、登録画面の「呼び名を変更」で直せます。

## 現地で確かめてほしいこと
- **ティーの位置**（推定。1・5・6・8番は表より直線が2割前後短く、ティーが実際より前に置かれている可能性があります）
- **ホール番号の順番**（図と写真の照合とつながりから決めました。違っていれば教えてください）
- 1番のクリーク・8番の右OBの線は登録していません（位置の資料が無いため）
- 写真は数年前のものです。リニューアル（2025年）で変わった所は反映されていません
- 18ホール回るときは、前半・後半とも同じ9ホールを選ぶ形になります（ラウンド設定の初期値がそうなっています）
