# ゴルフナビアプリ 設計メモ

作成日: 2026-10-13
状態: 案Aで確定し、v0.1.0 を実装済み（2026-10-13）。

## 決定事項（2026-10-13 ユーザー回答）
- 端末: Android（Chrome）。画面ON固定（Wake Lock）が使える
- コース: 太田双葉カントリークラブ（群馬県太田市西長岡町1524、愛宕・天王・御所ノ入の27ホール）
  - OSM はコース外枠と池（8か所）のみ。ホール・グリーン・バンカーは無し → **案Aで確定**
  - 標高データは「5m（レーザ）」がある（高精度）
- 距離: ヤードのみ（高低差はメートル表示）
- 競技では使わない → 高低差を消す「競技モード」は作らない

## 要望
スマホで使う。表示するもの: コースレイアウト / 高低差 / 残り距離 / ハザードまでの距離。

## 前提（調査で分かったこと）
- **コースデータ**: OpenStreetMap の golf タグにホールまで描かれた国内コースは、推定で全体の1割未満（2026-10-13 に Overpass で件数を実測）。Overpass は混雑して 504 エラーが多い。→ **自分で登録する機能が必須**。
- **高低差**: 国土地理院の標高タイル（DEM5A/5B/10m）や標高API を使う。スマホGPSの高度は精度が低いので使わない。
- **地図**: 国土地理院の航空写真（seamlessphoto, ズーム14〜18）。出典表示が必須。
- **GPS**: HTTPS 必須。LAN 内の http 配信（筋トレアプリの serve.py 方式）では現在地が取れない。iPhone は画面ロック中に位置更新が止まる。
- **規則**: 競技では高低差の表示自体が規則4.3違反 → 高低差を消す「競技モード」を付ける。

## 3案
| | 案A 手登録（推奨） | 案B OSM取込＋手補完 | 案C サーバー併用 |
|---|---|---|---|
| 内容 | 航空写真上でグリーン・ハザードをタップ登録 | OSM から1回取得して変換、足りない分を手登録 | Workers で中継・保存、コース名検索・共有 |
| 構成 | 静的PWA＋Leaflet＋JSON＋GitHub Pages | 案A＋取込ツール＋多角形計算 | Pages＋Workers＋KV/D1 |
| 手間 | 週末2回程度＋1コース30〜60分の登録 | 案Aの1.5〜2倍 | 案Aの3〜4倍＋運用 |
| 捨てるもの | 形のベクトル描画、任意コースの即時利用 | 実装の単純さ、Overpass の安定性 | サーバー無しの気楽さ |

案A のデータ形式は多角形（polygon）欄を持つので、後から案B の取込を足せる。

## ファイル構成（案A）
```
index.html        プレー画面
editor.html       コース登録画面（PC推奨）
js/geo.js         距離・方位・図形計算
js/elev.js        標高タイルの読み取り
js/play.js        現在地の監視・Wake Lock・表示更新
js/editor.js      登録画面の処理
css/style.css
vendor/leaflet/   Leaflet を同梱（圏外対策）
courses/          コースJSON（index.json が一覧、ota-futaba.json）
manifest.webmanifest, sw.js, icons/
tests/            node --test で実行
```

## データ形式
`courses/ota-futaba.json` を参照。ホールは `nines`（9ホールのまとまり）の中に入れる。前半・後半で2つ選んで18ホールにする。座標は `[緯度, 経度, 標高(任意)]`。
- ハザード `type`: `bunker | water | lateral_water | ob | other`
- `points` 1点=代表点、2点=手前と奥。`polygon` があればそちら優先。
- 標高は登録時に保存し、プレー中の通信を減らす。

## 実装順序
1. 航空写真の地図＋現在地を GitHub Pages で公開し、実機でGPSを確認
2. 地図タップ地点までの距離（データ無しでも距離計として使える）
3. コース登録画面 → 最初の1コースを登録
4. プレー画面（前・中央・奥、ハザード一覧、ホール切替）
5. 高低差（標高タイル）＋競技モード
6. PWA 化（コース範囲の地図を事前保存、版番号付きキャッシュ）
7. 実地テスト（ヤード杭との誤差確認）
